# MySQL 空检验数据库

> 当前项目结构：`backend/`（Spring Boot）+ `frontend/`（静态前端）。  
> 原“包含前端和源码的整包”说明已不再适用。

本目录包含空库初始化脚本 `初始化空库.sql` 和 Spring Boot 后端源码。MySQL Connector/J 已包含在后端 JAR 中。前端在项目根目录的 `frontend/`。

1. 在 MySQL 8.x 管理工具中执行「初始化空库.sql」。它创建 medical_inspection 库及 inspections 表，无预置记录，不清理同名库中的数据。
2. 创建专供后端使用的 MySQL 用户，授予该库 SELECT、INSERT 和 UPDATE 权限。
3. 配置后端环境变量 SKIN_STORAGE_TYPE=mysql、MYSQL_URL（如 jdbc:mysql://127.0.0.1:3306/medical_inspection）、MYSQL_USERNAME、MYSQL_PASSWORD。检查图片仍保存在 SKIN_STORAGE 指向的目录，建议为新库使用独立的目录。
4. 将 FRONTEND_LOCATION 设为前端文件夹的 file: 地址（末尾有斜杠），按原项目方式配置医生和管理员的登录账号，再使用 JDK 21 运行 java -jar skin-backend-1.0.0.jar。
5. 打开 http://127.0.0.1:5175/login.html（如设置了其他 PORT，请使用该端口）。管理员可在「系统状态」查看 MySQL 状态。医生页面可能包含标为示例的前端演示数据，它不写入 MySQL。

不设置 SKIN_STORAGE_TYPE 时，原有部署继续使用文件存储。
